# M02 Генератор предметов — research (2026-11-24)
Sources: Diablo II — classic.battle.net/diablo2exp/items/magic.shtml (магические: префикс/суффикс, ilvl), crafteditems.shtml (число аффиксов по ilvl), purediablo.com/d2wiki/Affix.

## How the references do it
- D2: магический предмет = префикс и/или суффикс, никогда два префикса или два суффикса; шансы: оба 25%, только префикс 25%, только суффикс 50%.
- Аффиксы выбираются из тех, что возможны на этом типе основы, с уровнем аффикса ≤ ilvl+2 → тип предмета ограничивает свойства, глубина открывает сильные.
- Редкие — сильнее магических, жёлтое имя; количество аффиксов растёт с ilvl (у крафта 1–4).
- Имена редких — два случайных слова, не описывают свойства.

## Decision
- Предмет = тип (постоянный профиль, решение #28) + аффиксы: обычный 0, магический 1–2, редкий 3–4, легендарный 5 (сильнее ×1,3). Один аффикс на стат.
- Каждый аффикс привязан к слотам (шипы — броня/щит/шлем; пробивание — оружие/перчатки/кольца…).
- Рост: плоские статы +8%/глубину, процентные +3%/глубину (не улетают в бесконечность).
- Имена: магический — «Топор вампира» (родительный падеж — без проблем с родом); редкий/легендарный — два слова «Скорбь пепла», тип — в подзаголовке.
- Новые статы: сила крита, пробивание брони, шипы, регенерация, алчность (+% монет) — «больше статов» из PT-02.
Risk: 12 статов перегрузят карточку → на карте только изменившиеся строки, в панели героя — только ненулевые доп. статы
