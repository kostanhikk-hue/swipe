# Assets — research (2026-11-24)
Game: 2D, гравюра на пергаменте (ART_BIBLE), Godot 4.6.2, решение #11: сначала заглушки кодом, потом рисунки.

## Findings
- Процедурная гравюра в Godot работает: штриховка, обрезанная по полигонам (Geometry2D.intersect/clip_polyline), радиальные штрихи для перспективы, очищенная бумага под надписями. Проверено в лук-деве.
- Цена: тысячи линий; на программном рендере VM 5 fps, на реальном GPU норм — к слайсу запекать статичные слои в текстуру (SubViewport → ImageTexture).
- Публичный домен с настоящей гравюрой: Met Open Access (CC0, 490 тыс. изображений, API) и Wikimedia (Дюрер и др.) — подходят для врагов и предметов. Из оболочек агента сейчас недоступны (сеть VM пускает только GitHub) — скачивание делает пользователь или браузер.
- Генерации картинок в этой сессии нет.
- Шрифт: Cormorant Garamond (OFL, кириллица, переменный вес) — антиква «гравюрного» вида, взят с GitHub google/fonts.
- Звук: CC0-наборы (Kenney, freesound CC0) — к фазе 6–7, сеть та же проблема → скачать через браузер.

## What this changes
- Враги, предметы, коридор, UI — процедурно в коде (Engrave), как и решено; замена на рисунки — без изменения кода (по имени в data/).
- Публичный домен — вариант для «настоящих» рисунков позже; решает пользователь.
